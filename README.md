## About Municipal Governance AI Copilot

Municipal Governance AI Copilot is a civic-tech tool built to help city and municipal teams work through research, planning, and review tasks with less manual effort. It focuses on day-to-day government workflows such as policy exploration, budget inspection, and preparing for meetings, making it useful for staff who need faster access to organized information.

The project combines AI-assisted analysis with practical publishing and export options so teams can move from review to sharing without switching tools repeatedly. It is positioned as an open-source, local-government-oriented companion for staff who handle ordinances, budget documents, and cross-language materials.

## Features

- Automated meeting preparation for agendas, notes, and briefing materials

- Budget review support with anomaly detection for closer inspection
- Ordinance conflict analysis to help compare rules and identify issues
- Multilingual document support for working across different languages
- Responsive multi-device UI for desktop and mobile-friendly access
- Claude and OpenAI integration for flexible AI-assisted workflows
- Multi-format export for sharing outputs in several common formats

## Usage

Use the copilot as a working companion for municipal tasks such as:
- preparing meeting packets and discussion notes
- checking policy background before a session
- reviewing budget items for irregularities or unusual patterns
- comparing ordinances for possible conflicts
- handling documents in more than one language
- exporting results for internal review or distribution

Typical workflow:
1. Load the relevant document set or topic.
2. Ask for a policy, budget, or ordinance review.
3. Review the generated analysis and refine the request if needed.
4. Export the output in the format that fits your process.
